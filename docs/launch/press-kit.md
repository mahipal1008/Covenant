## One-liner

Covenant is a living-intelligence platform that catches
tenant-isolation bugs in B2B SaaS before they reach a customer.

## Two-paragraph version

Every multi-tenant SaaS ships the same bug exactly once: a query that
forgets the organization filter and returns one customer's data to
another. Covenant prevents that bug — and the dozens of related
auth-coverage, intent-drift, and audit-trail gaps — by indexing the
*intent* of a codebase, not just its surface.

It plugs in via a GitHub App and produces actionable findings on
every pull request, including a failing reproduction the engineer
can run locally. The platform ships with a CLI on npm, an SDK on
PyPI, extensions for VS Code and JetBrains, and a self-hostable
Helm chart for regulated customers.
