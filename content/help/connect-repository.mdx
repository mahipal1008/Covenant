# Connect your first repository

You can wire Covenant to your code in three ways: the GitHub demo
provider, a public clone URL, or the official GitHub App for
production workspaces.

## Three connection paths

- **Demo provider** — instant, uses our seeded sample repository.
- **Public clone URL** — fastest path to scanning your own code.
- **GitHub App** — required for private repos, PR checks, and webhooks.

## What happens after connect

Covenant indexes file structure, dependencies, and intent within
thirty seconds. The semantic graph populates and the first
multi-tenant scan is queued automatically.
